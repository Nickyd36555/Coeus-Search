Facebook Marketplace car monitor · Windows

Getting fbmarket running

From an empty PowerShell window to Discord buzzing when a car you actually want hits Marketplace. Twelve steps, four checkpoints, about twenty-five minutes.

Time ~25 min You need Windows 10 or 11 Alerts go to Discord

Install it

Steps 1–5
1

Open PowerShell

Press Win + X and choose Terminal (Windows 11) or Windows PowerShell (Windows 10). Every command in this guide goes in that window.

Check you're not in Command Prompt

Windows has two lookalike terminals and only one of them works here. Look at your prompt: 

PS C:\Users\you>      <- PowerShell. Correct.
C:\Users\you>         <- Command Prompt. Wrong - close it.

If the PS is missing you're in Command Prompt, and roughly half the commands below will fail with confusing errors. Close it and open Terminal or Windows PowerShell instead.

Do the steps in order

Each step depends on the one before it. Step 12 in particular can't work until steps 4 and 5 have downloaded and installed the project.

Keep one window open

Use the same PowerShell window the whole way through. Several steps depend on the one before it, and opening a fresh window resets that.

2

Install Python and Git

Check what you already have:

> python --version
> git --version

You want Python 3.10 or newer. If either command errors, or Python opens the Microsoft Store instead of printing a version, install them: 

> winget install Python.Python.3.12
> winget install Git.Git

Close PowerShell and open a new window afterwards, then re-run both version checks before continuing. A window that was already open cannot see newly installed programs, so git will still look missing until you do.

If winget isn't available
# Download the installers manually:
#   python.org/downloads   -> TICK "Add python.exe to PATH" on screen one
#   git-scm.com/download/win -> accept all the defaults
The Microsoft Store trap

If python --version opens the Store rather than printing a number, Windows is using a placeholder rather than real Python. Search “Manage app execution aliases” in the Start menu and switch off both python.exe and python3.exe, then install from winget or python.org.

3

Allow PowerShell to run the environment script

Windows blocks local scripts by default, which stops the next step dead. Clear that for your own account only: 

> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Answer Y when it asks.

Wait for prompts to finish

When any command asks [Y] Yes [N] No:, type Y and press Enter before pasting anything else. Paste a command into that prompt and it gets swallowed as your answer — it never runs, and nothing tells you so.

This affects your user account, not the whole machine, and only permits scripts you wrote locally — downloaded scripts still need to be signed.

4

Download the code

> cd $HOME
> git clone https://github.com/Nickyd36555/Coeus-Search.git
> cd Coeus-Search

That puts the project in C:\Users\<you>\Coeus-Search. Every later command runs from inside that folder.

5

Set up the environment and install

> python -m venv .venv
> .venv\Scripts\Activate.ps1
> pip install -e ".[web]"
> playwright install chromium

The last line downloads the browser it drives — about 150 MB, once. Marketplace only renders listings for a real browser, which is why this is needed.

Checkpoint

Your prompt should now begin with (.venv). Confirm the tool installed: 

> fbmarket --version
fbmarket 1.0.0

If you get “running scripts is disabled on this system”, step 3 didn't take — run it again. If you get “fbmarket is not recognized”, the environment isn't active: re-run .venv\Scripts\Activate.ps1.

Connect your alerts

Steps 6–7
6

Create a fresh Discord webhook

Do this one properly

The webhook you sent me is sitting in our chat transcript, so treat it as compromised — anyone holding that URL can post into your channel. Create a new one, and don't paste it into a chat again.

In Discord: Server Settings → Integrations → Webhooks → New Webhook. Pick the channel you want alerts in, then Copy Webhook URL.

Store it in a file called .env, replacing the URL below:

> Set-Content -Path .env -Value 'DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/PASTE_YOURS'

That file is already git-ignored, so the secret can't reach GitHub by accident, and the tool reads it automatically.

If you'd rather use Notepad

Run notepad .env and click Yes to create it. Don't create the file from File Explorer — Explorer silently saves it as .env.txt, and the tool won't find it.

7

Switch Discord on and prove it works

> Copy-Item config.example.yaml config.yaml
> notepad config.yaml

Find the discord block and change enabled: false to enabled: true, then save and close Notepad: 

    - type: discord
      enabled: true
      webhook_url: ${DISCORD_WEBHOOK_URL}

Now validate the config and fire a test alert:

> fbmarket check
> fbmarket test-notify
Checkpoint

A sample Tacoma listing should land in your Discord channel within a few seconds. Don't continue until it does — everything after this assumes alerts reach you, and a silent monitor is much harder to debug than a failing test.

Tell it what to hunt

Steps 8–10
8

Open the interface

> fbmarket web

Open http://127.0.0.1:8765 in your browser. Windows may show a firewall prompt the first time — Allow it for private networks. The page only runs on your own machine.

The example config ships with three placeholder searches pointed at Salt Lake City. Delete them once yours works. Click + New search and fill in the car, price range, years and mileage limit.

The one field that trips people up

Location. Open Facebook Marketplace in another tab and look at the address bar. Copy the part immediately after /marketplace/ — either a city name like manchester or a long number like 109470862423276. That exact value goes in the Location box.

Fill Reject if the listing mentions… generously — salvage, rebuilt, parts only, no title, wanted, lease. That field is what keeps junk out of your Discord. Then Save search.

9

Test the search and tune it

Press Test next to your search. It checks Marketplace live and lists every car on the page with a verdict on each — either would alert you, or the exact rule that rejected it, like skipped — price 26,900 > 25,000.

Adjust and re-test until the right cars pass. That's the whole point of the Test button: no guessing why you're getting junk, or nothing at all.

If you get zero listings

Facebook probably showed a login wall. Press Ctrl+C in PowerShell to stop the server, then run fbmarket login. A browser opens; log in normally, press Enter, and the session is saved on your machine. Then go back to step 8.

10

Take a baseline

Press Check once now on the dashboard.

This first pass stays deliberately silent. It records every car already listed so you don't get eighty notifications at once. From here you only hear about cars posted after this moment.

Keep it watching

Steps 11–12
11

Start monitoring

Hit Start monitoring on the dashboard. It now checks every ten minutes and posts anything new to Discord.

Checkpoint

The dashboard shows a green running pill, and Recently found fills up as cars appear. Your first real alert usually lands within an hour or two, depending on how busy your local market is.

12

Make it survive a reboot

It only alerts while it's running — closing PowerShell stops it. To start it automatically whenever you log in: 

> .\deploy\install-windows-task.ps1

That registers a Windows scheduled task, starts it immediately, and restarts it if it ever crashes. To check on it or remove it later: 

> Get-ScheduledTask -TaskName fbmarket
> Unregister-ScheduledTask -TaskName fbmarket -Confirm:$false
Stop your PC sleeping

This is the one that catches people out. A sleeping Windows machine checks nothing, so you'll silently miss cars overnight — exactly when good ones get listed. 

> powercfg /change standby-timeout-ac 0

That stops it sleeping while plugged in. The screen still turns off, which is fine. On a laptop, leave it on mains power.

When something goes wrong

Reference
“The system cannot find the path specified”

You're either in the wrong folder or the project isn't downloaded yet. Check both: 

> cd $HOME\Coeus-Search
> dir

You should see fbmarket, deploy and config.example.yaml. If cd itself fails, step 4 hasn't run — go back and clone the repository.

Also confirm your prompt starts with PS. In Command Prompt, .\deploy\install-windows-task.ps1 cannot run at all.

“git is not recognized”

Git isn't installed yet, or the window predates its install:

> winget install Git.Git

Then close PowerShell and open a new window. A window that was already open cannot see programs installed after it started — this is the single most common reason a fresh install "doesn't work".

If winget reports "Found an existing package already installed" but git is still not recognized, it's installed and simply missing from this window's PATH. Reload PATH without reopening: 

> $env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User")
> git --version

Still nothing? Point at it directly:

> $env:Path += ";C:\Program Files\Git\cmd"
> git --version

No luck, or you'd rather skip Git entirely? Download the code as a zip:

> cd $HOME
> Invoke-WebRequest "https://github.com/Nickyd36555/Coeus-Search/archive/refs/heads/claude/facebook-marketplace-car-monitor-8dzoyc.zip" -OutFile coeus.zip
> Expand-Archive coeus.zip -DestinationPath .
> Rename-Item "Coeus-Search-claude-facebook-marketplace-car-monitor-8dzoyc" Coeus-Search
> cd Coeus-Search

That gets you the same files. You just won't be able to git pull for updates later.

“running scripts is disabled on this system”

Step 3 didn't apply. Run it again and answer Y:

> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

If your workplace manages this PC, that policy may be locked. Use .venv\Scripts\activate.bat from cmd.exe instead — it isn't affected.

“fbmarket is not recognized”

The virtual environment isn't active in this window. From the project folder: 

> cd $HOME\Coeus-Search
> .venv\Scripts\Activate.ps1

You need that in every new PowerShell window. Your prompt should show (.venv).

“python was not found” or it opens the Microsoft Store

Windows is using its placeholder rather than real Python. Search “Manage app execution aliases” in the Start menu, switch off python.exe and python3.exe, then install with winget install Python.Python.3.12 and open a new window.

The test alert never arrived in Discord

Run fbmarket check — the last line lists the active channels. If it says NONE, the enabled: true edit in step 7 didn't save.

If it says discord but nothing arrives, the URL in .env is wrong or the webhook was deleted. Confirm the file is really called .env and not .env.txt: 

> Get-Content .env
“No listings were found on the page at all”

Usually a login wall. Run fbmarket login and retry.

If that doesn't fix it, capture what Facebook actually returned. Add this to config.yaml under browser::

browser:
  debug_dump_dir: ./debug
  headless: false

Run fbmarket once -v, then inspect the saved page with fbmarket parse debug\<file>.html. With headless: false you'll see the browser window and can watch where it gets stuck.

Listings are found, but nothing passes my filters

Press Test and read the reason on each rejected car — it names the exact rule. The usual culprit is a mileage or year limit catching cars whose title doesn't state a year.

I'm getting junk alerts — salvage, parts, wanted ads

Add those words to Reject if the listing mentions… in the search form. It matches the title, subtitles and location, and is case-insensitive.

I want to be re-alerted about cars it already found

Press Reset next to that search. It clears the memory for that search only, so the next check treats everything as new.

Facebook started blocking or challenging me

Slow it down. In config.yaml, raise poll.interval_seconds to 1800 — every 30 minutes. For cars that's still far faster than refreshing by hand, and much less likely to draw attention.

Re-run .venv\Scripts\Activate.ps1 in every new PowerShell window. Project folder: C:\Users\<you>\Coeus-Search
